Back to top

iPhone · 5 минут

  1. Open Shortcuts → Automation → Time of day → Daily.
  2. Add actions: “Get Contents of URL” → “Set Wallpaper”.
  3. Paste the generated link into the URL field and choose Lock Screen.

Android · 10 минут

  1. Pick any automation app (MacroDroid/Tasker) and create a daily trigger.
  2. Fetch the URL from this generator and save it to a file.
  3. Set that file as the lock screen wallpaper.

Tips

  1. Preview updates instantly when you change parameters.
  2. If preview caches, the automation will still refresh daily.
  3. Use color palettes to match your lock screen.
